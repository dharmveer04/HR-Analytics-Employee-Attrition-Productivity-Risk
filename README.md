# Project 3: HR Analytics – Employee Attrition & Productivity Risk

## 📌 Project Overview
This project focuses on analyzing employee attrition and productivity risk using HR data.  
The goal is to help HR teams identify high-risk employees, departments, and job roles to enable proactive decision-making.

The project follows an end-to-end data analytics workflow using:
- SQL for data querying
- Python for feature engineering
- Power BI for interactive dashboards

---

## 🛠 Tools & Technologies Used
- **MySQL** – Data storage and SQL analysis  
- **Python (Pandas, NumPy)** – Data cleaning and risk classification  
- **Power BI** – Dashboard creation and visualization  

---

## 📂 Dataset Description
The dataset contains employee-level HR information, including:
- Demographics (Age, Gender, Department, JobRole)
- Work-related factors (OverTime, JobSatisfaction, WorkLifeBalance)
- Performance metrics (PerformanceRating)
- Attrition status (Yes/No)

Additional engineered fields:
- `attrition_risk` (Low / Medium / High)
- `productivity_risk` (Low / Medium)

---

## 📊 Dashboard Structure

### 🔹 Page 1: HR Overview
- Total Employees
- Attrition Count
- Attrition by Department
- High-level workforce health summary

### 🔹 Page 2: Attrition Risk Analysis
- Employee distribution by attrition risk
- Department-wise attrition risk comparison
- Identification of high-risk employee segments

### 🔹 Page 3: Productivity Risk Analysis
- Productivity risk by job role
- Performance rating vs productivity risk
- Employees requiring performance intervention

---

## 🧠 Key Insights
- Research & Development shows the highest attrition volume
- Certain job roles consistently fall under high attrition risk
- Medium productivity risk is dominant across departments
- Performance rating alone does not fully explain attrition risk

---

## 🎯 Business Impact
This dashboard enables HR teams to:
- Identify employees at risk of leaving
- Detect productivity issues early
- Focus retention strategies on critical roles
- Make data-driven HR decisions

---

## 📌 Conclusion
The project demonstrates how HR analytics can be used to convert raw employee data into actionable insights using SQL, Python, and Power BI.  
It reflects a real-world, industry-level analytics use case.
